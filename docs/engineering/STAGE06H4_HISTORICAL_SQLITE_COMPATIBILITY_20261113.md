To make future producer outputs actionable, the current

true saved native version 86–135. The new
`Stage06H4NativeCompatibility.py` is the provenance gate:

bytes after execution. A header or fabricated backup is not evidence.

historical household, medical encounter, high-order galactic position
or finite planetary resource. Future producer tests must exercise
those capabilities with real original game commands before claiming
their version-specific functional coverage.
