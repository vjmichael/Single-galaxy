# S6-H2 — Original physical galactic movement and durable worker handoff
**Development source:** `sg/stage6f5e-installed-terrain-recovery-20261112`. **Acceptance:** mandatory exact-head native Windows/Linux CTest; physical installed game, PC SCM, Radeon and release work are deferred.

## Real authority boundary
1. The existing original `Action::Thrust` performs a genuine 250 mm physical crossing of the 1e15-mm galactic sector boundary. The same `PersistentWorld::commit` writes the original ship, snapshots and immutable `sg_spatial_native_transfer` migration. No worker can write its own ship, NPC, resource or world tick.
2. The separate original authorized `Action::RequestJump` to a real gate changes the ship's catalogue system only under existing native transit rules. H2 does **not** invent instantaneous interstellar travel or a new engine; it handles worker reassignment after the authentic arrival.
3. The host-only `reconcile_committed_ship_handoff` requires the verified original destination `ship_cell`, latest immutable ship migration sequence, matching origin/destination, owner, world generation and spatial index. It additionally validates the regional authority and both expected worker epochs.
4. A **single** SQLite `BEGIN IMMEDIATE` transaction retires a now-empty source lease, advances the destination worker via CAS, appends the original destination worker-transfer record and an immutable ship-handoff audit. A source with another real ship retains its lease. Both source and destination reject replay, forged location, conflicting transfer ID, stale epoch, untrusted host and stale original snapshot. `FailPoint::AfterSnapshotWrite` injects an interruption after retiring the source but before admitting the destination; rollback must leave both leases unchanged.
5. An OS worker is read-only; the new coordinator updates only worker responsibility and never transforms game state. A post-movement crash may leave the old source lease temporarily present, but the original writer claim already refuses an empty physical source cell; host restart completes the exact durable handoff, not a second world movement.
