- `desktop_godot/world/native_planet_surface_session.gd` uses the existing SGDX-supervised original host process and verified `PFRAME`/denial protocol. Replay, source mismatch, stale generation and impossible pose refuse/stop the session. The installed `main.gd` routes original Godot WASD intents here only after verified live native custody, and displays **the host-acknowledged** original X/Y/Z and source. F9 is an **explicit opt-in** to an already landed original saved player, never permission to land. It requires `user://single_galaxy_authoritative.sqlite`; an absent or unlanded world refuses, and the original host process must be stopped before opening the same save.
- **Reconciled writer protection:** the standalone and colony hosts previously took **different** process-lifetime sidecar locks, potentially permitting stale in-memory writers against the same SQLite database. `NativeWriterLease` now takes *both* `.sg-native-writer.lock` and the established canonical `.host.lock`; the original colony host uses this same dual lease. A still-running host prevents this new planet mode from starting. The F6 reset pathway is disabled while the planetary writer is active.

## S6-F5-C vertical physics — source foundation, not live production physics

`PlanetaryVerticalPhysics.hpp` is an explicit, deterministic, fixed-point radial solver with bounded 20–250 ms steps. It models jump velocity, gravity acceleration, free-fall and contact on *native-supplied* ground; returns impact velocity **as a proposed evidence/result**, without directly injuring a player. Existing `PhysicalHazard` enumerations allow source-backed thermal-exposure accounting. Oxygen drain requires both a **verified native supply** and source-provided consumption rate; neither atmosphere nor protection is fabricated.

It will **refuse** without a native gravity observation. The current authoritative planetary catalogue contains physical radius but not sufficient independently verified mass/density to infer body-specific gravity; choosing Earth g by default would be a false simulation. No `Simulation`/SQLite v134 vertical velocity, suit state, injury or environmental-survival ledger is yet implemented. CTest `galaxy_stage6f5c_vertical_physics` asserts mathematical behavior and is **registered, not executed**.
