SINGLE GALAXY / MATRIX VISION  —  B3.2 VISUAL REPLAY

Windows quick start:
1. Unzip this folder normally.
2. Double-click index.html; use Edge or Chrome.
3. Select one of the three scenarios and press Play.
4. The timeline lets you step through actual recorded simulation ticks.

No install, Python, server, network, or EVE assets needed to view the bundled demos.
This is a read-only REPLAY, not a live game. To create new recordings,
use the C++ source and galaxy_visual_scenario_recorder from the full-source archive.
