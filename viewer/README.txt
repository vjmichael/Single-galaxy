SINGLE GALAXY / MATRIX VISION  —  B3.2 VISUAL REPLAY

Windows quick start:
1. Unzip this folder normally.
2. Double-click index.html; use Edge or Chrome.
3. Select one of the three scenarios and press Play.
4. The timeline lets you step through actual recorded simulation ticks.

No install, Python, server, network, or EVE assets needed to view the bundled demos.
This is a read-only REPLAY, not a live game. To create new recordings,
use the C++ source and galaxy_visual_scenario_recorder from the full-source archive.

ECON-02B2d4b FREEFORM FACTORY DESIGNER:
Open factory.html in your browser (Chrome or Edge). Click Load example to explore.
The snap-to-edge Wall/Door tools draw connected rooms. Place one 1x1 base
storage, additional 1x1 4m3 containers, and one 2x2 Tier-1 workshop.
Select Auto-route conveyor; click source then destination. Use Save design
for .sgfactory (editable walls/floors included) or Export .sglayout for
the native C++ FactoryLayout/BlueprintConstruction planner. Both formats
can be reopened. No server, install, or npm packages are required.
IMPORTANT: Offline browser editor is NOT a running game or trusted host.
Exporting a blueprint never creates any items. Walls, doors, floors
are aesthetic/design overlays, NOT supported durable construction yet.
