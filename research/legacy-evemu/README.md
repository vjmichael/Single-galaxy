# Legacy EVEmu research preservation

This directory holds the **separate, historical EVEmu educational research** preserved from ChatGPT Library on 2026-10-31. It is not part of the original Single Galaxy game implementation and should not be compiled or imported into the game.

- `EVEmu_Complete_Library_Backup_2026-10-31.zip` contains 49 original Library files (34 from `/Eve-Mu`, 15 from the root).
- The manifest records filenames and SHA-256 hashes.
- The `.sha256` file verifies the ZIP itself.

Preserved for historical audit and provenance only. Do not conflate this upstream-related research with the original Single Galaxy code or assume rights to redistribute upstream materials.
