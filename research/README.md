# Historical EVEmu reports (user supplied, read-only)

`evemu_client_server_interaction_report_original.md` and `evemu_client_server_calls_original.csv` are retained as uploaded, not endorsed as independently verified source or integration evidence.

`evemu_client_server_calls_normalized.csv` reconstructs 68 numbered records, 10 fields each. It is generated by `repair_uploaded_evemu_calls.py`, addressing structural CSV quoting/column issues while preserving the original self-reported status labels. This is a syntax repair, **not** an EVEmu runtime-compatibility validation.

See the main B6.2c engineering report for evidence cautions and applicability to the original game.
